# Optional canonical ClockEra serialization adapter

**Version 0.1.0**; opt-in public header `<serialisation/ClockEraAdapters.hpp>`, not imported by default `ESPressio_Serialisation.hpp` or `serialisation/Serialisation.hpp`. Consumers explicitly import the header AND declare an **optional conditional EDP-Clock dependency** (activated only with this adapter). Dependency direction is **EDP-Serialisation → EDP-Clock → EDP-Platform/EDP-System**, never the reverse. EDP-Clock's existing owner stays unchanged; no Mesh concrete library is imported.

`CanonicalRepresentation<ESPressio::Clock::ClockEra>::Type` is exactly `std::uint64_t`. The two EDP-BoundedTypes `TypeConversionAdapter` specializations implement lossless, constexpr/noexcept ClockEra→uint64 via the owner's `Value()` and uint64→ClockEra via the owner's `FromValue()`. `SerialisableType<ClockEra>` is statically certified when the header is explicitly included. CBOR uses the **existing** Serialisation canonical unsigned integer encoding, JSON the existing decimal integer encoding; no new wire codec or runtime registry. `ClockEraAdaptationResult::Succeeded` means a value was reversibly converted, **NOT** evidence it originated from an authorised upstream coordinator. A zero ClockEra is still a valid *representation* of the invalid/unavailable sentinel and remains invalid at the temporal provenance layer.

Use case: application-level explicitly opted-in strong ClockEra diagnostic values once a **real coherent Clock/coordinator sample** has established the era. **This does not implement G2**: it neither issues nor validates an Era, cannot prove synchronisation or epoch continuity, and does not produce a coherent Monotonic/Sync/Uncertainty capture. Logging's existing `LogTemporalEvidence.hpp` still requires a genuine upstream coherent producer, and G4's governed LogRecord root identity remains blocked under EDP-System#11.

Test `tests/host/clock_era_adapters.cpp`: reverse canonical strong type, exact CBOR golden `81 1B 01 02 03 04 05 06 07 08`, JSON `[72623859790382856]`, output buffer transactional no-mutation, and zero sentinel propagation. Runner `tests/run-clock-era-adapters-tests.sh` with actual Clock/System/BoundedTypes dependencies, GCC+Clang, and Xtensa syntax-only. This opt-in addition preserves existing default Serialisation owner/consumer behavior.
