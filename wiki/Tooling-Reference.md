# Tooling Reference

EDP-Serialisation currently contains **no substantive maintained product tooling** such as a compiler, generator, schema processor, validator CLI, or decompiler.

`tests/run_host_tests.sh`, CMake configuration, PlatformIO projects, and `.github/workflows/validate.yml` are build/validation surfaces documented in [Build, Test and Source](Build-Test-and-Source); they are not presented as product tooling APIs.

If later Serialisation work introduces maintained command-line or code-generation tooling, this page must become its first-class module/command/reference index in the same implementation slice.
